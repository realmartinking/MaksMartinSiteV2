# Аудит Folder — 16 сентября 2026

Сравнение версии `0d0f4cb` с приложенным видео LE:MA и двумя скриншотами. Авторская публикация: [Lazarev — LE:MA cases animation](https://dribbble.com/shots/26172755-AI-Landing-page-website-design-cases-animation-LE-MA).

## Что было неверно

1. **Полосы вместо перекрытия.** В предыдущей версии весь видеокадр поворачивался на 68° и помещался в узкую полосу. В референсе видна верхняя часть полноценной карточки: её нижнюю часть закрывает следующая. Это главное визуальное расхождение.
2. **Слишком сильная трапеция.** Независимая короткая перспектива вместе с сильным наклоном заметно искажала весь кадр. В референсе глубину прежде всего показывают постепенное изменение размера и перекрытие.
3. **Раскрытие в произвольном месте.** Hover раскрывал карточку там, где она находилась. По уточнённому заданию hover должен показывать название, а клик — центрировать выбранную карточку и раскрывать только её.
4. **Наложение раскрытой карточки.** Прежний `z-index: 500` помещал её поверх соседей. Соседи получали одинаковый сдвиг, сохраняя угол. В референсе меняются расположение и перспектива обеих частей стопки.
5. **Блокирующий скролл.** После двух шагов старый обработчик игнорировал остаток непрерывного жеста; новый ввод мог ждать паузы. Это программное ограничение, не проблема Интернета.
6. **Неверное место названия.** Подписи находились на каждой плоскости и деформировались вместе с ней. Нужен отдельный неподвижный текст слева по центру.

## Что изменено

- Закрытая стопка строится из перекрывающихся полноразмерных видеокадров. Видимая часть центрального проекта выровнена с вертикальным центром экрана. Полный контейнер находится ниже этой видимой части — выравнивание сделано по объекту, а не по скрытому контейнеру.
- Ширина базовой карточки 40.5% окна; после проекции видимая верхняя грань около 42%. Ширина открытой карточки около 34%. Эти пропорции подобраны по кадрам референса, а не извлечены из его исходного кода.
- Hover/focus показывает название слева. Клик сначала приводит выбранный индекс к центру, затем открывает его. Новое движение или Escape закрывают выбор. Новая карточка не раскрывается, пока не центрирована.
- Один параметр раскрытия управляет выбранной карточкой и обеими частями стопки. Ближние карточки изменяют перспективу сильнее, дальние уходят назад. Обычный порядок перекрытия сохраняется; искусственного поднятия выбранной карточки над стопкой нет.
- Расстояния учитывают спроецированные края на каждом промежуточном кадре. Видимая доля выбранного кадра постепенно увеличивается; после раскрытия снизу остаётся свободный интервал, а верхние карточки продолжаются за выбранной плоскостью.
- Движение колеса передаётся непрерывно, с инерцией. После 140 мс без ввода позиция доводится до целого индекса. Короткий жест завершает один шаг; ввод примерно на высоту окна — около двух. Продолжение скролла и смена направления принимаются во время анимации.
- Сохранены бесконечный цикл четырёх проектов, ограниченное число элементов, исходные видео, тёмная тема и существующие остальные виды Production.

## Проверки и границы вывода

Автоматические проверки покрывают короткий/полный жест, продолжение после двух проектов, одинаковый результат при объединении событий, смену направления, перекрытие без сплющивания кадра, раскрытие одного центрального проекта, постепенное освобождение его границ и бесконечный индекс.

Браузерная проверка на окне 1422×800: два коротких жеста дали 0 → 1 → 2, более сильный — 2 → 4. Во всех случаях конечная позиция целая, число элементов остаётся 21. Фокус показывает подпись слева без раскрытия. Выбор верхней карточки приводит её к центру и открывает только один проект. У референса другие изображения и пропорции контента: повторение четырёх видеопроектов не будет выглядеть как десять разных макетов сайтов. Геометрия и поведение восстановлены по видео; утверждения о совпадении исходных углов, таймингов или исходного кода нет. Это аудит движения и композиции, а не новый замер FPS или гарантия производительности Safari.


## Уточнение по стопкам и Roll

Повторная сверка с кадрами раскрытия из видео (примерно 1.25–2.35 с) и новыми скриншотами выявила три расхождения версии `2363589`: задние карточки слишком наклонены и целиком вынесены наверх; закрытая стопка слишком плотная; декоративная обводка рисует тонкие выступающие края.

- Шаг закрытой стопки увеличен с 8.2% до 11.45% высоты окна. При остановке видны десять карточек, включая частично видимые у границ. Между остановками число не превышает десяти. В DOM остаются буферные карточки для бесшовного продолжения в обе стороны.
- Задние плоскости раскрытой стопки почти выпрямляются (5–10°), уменьшаются в глубину и продолжаются за центральной карточкой. Видны верхние полосы; их низ перекрыт следующей плоскостью с естественным порядком слоёв.
- Спереди после раскрытия видны три карточки. Шаг рассчитан по оставшемуся месту до нижнего края окна; четвёртая находится за ним. Зазор под основным видео — 2.5% высоты окна, минимум 16 px (20 px на окне высотой 800 px).
- Декоративная обводка удалена. Клавиатурный фокус обозначен внутри карточки, без внешних тонких линий.
- Roll сохраняет прежние коэффициенты движения и инерции. После 160 мс без ввода целевая позиция округляется до ближайшего проекта. Для touch доводка начинается после отпускания; новый ввод прерывает её без блокировки.

Дополнительные проверки геометрии покрывают максимум десять видимых полос на всём промежутке между проектами, постепенное раскрытие без наезда передней стопки, перекрытие и уменьшение задних карточек, три передние карточки на пяти десктопных пропорциях окна. Референс задаёт композицию, а не точные исходные коэффициенты CSS.

В локальном браузере проверены: закрытая стопка из десяти полос; раскрытая карточка с зазором 20 px при высоте окна 800 px и только тремя передними полосами; выбор из нижней стопки (индекс 2) с одним раскрытым проектом; короткий жест закрытия 2 → 3. Roll после неполного жеста остановился на 1.0000, после сильного жеста с обратным вводом — на 2.0000; окно DOM осталось из семи карточек. Ошибок браузера нет.
